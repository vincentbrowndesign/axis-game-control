## Rules Before Adding a Row

1. Confirm the license allows reading/reference (and, separately, whether it allows reuse of code).
2. Read the architecture, not just the README or demo GIF.
3. Do not run the repo's setup scripts without reading them first.
4. Record the pattern in your own words - do not paste their code into Axis.
5. Only wire a pattern into Axis behind an existing or new inactive feature flag, one capability at a time.
