## Rules

1. Search public GitHub.
2. Save useful repos into `docs/research/ai-basketball-repos.md`.
3. Check the license before treating anything as usable reference.
4. Inspect architecture only, not just the README.
5. Never run unknown setup scripts blindly.
6. Extract patterns, not copy/paste apps.
7. Add one capability to Axis at a time.
8. Keep everything behind `AGENTS.md` / `CLAUDE.md` rules.

Do not perform internet search in code unless explicitly asked.
