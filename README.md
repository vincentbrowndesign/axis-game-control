# Trophy Labs / Axis

Low-tech rebuild.

Trophy Labs is the public sports intelligence lab.
Axis is the internal operating brain.
Player Intelligence is the customer-facing product language.

First product:

```text
Trophy Labs Player Intelligence Session
-> Parent Recap
-> Proof Clips
-> Player Intelligence Report
-> Next Objective
-> Follow-Up Offer
```

This repo starts as plain HTML/CSS so the manual product can be shaped before adding tools, auth, databases, computer vision, dashboards, or automation.

Open `index.html` for the public page.
Open `axis.html` for the operator worksheet.
